# np

Next.js project.

See `PROJECT_CONTEXT.md` for the project overview, architecture, request flow, environment variables, and current implementation caveats.

## Prerequisites

- Node.js: `>= 20`
- npm or yarn

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
